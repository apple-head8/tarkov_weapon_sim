# Tarkov 武器ビルドシミュレーター

Escape from Tarkov の武器・パーツ・弾薬を組み合わせて、価格や性能の変化を確認できる武器ビルドシミュレーターです。

## 公開URL

https://apple-head8.github.io/tarkov_weapon_sim/

## できること

- 武器を選択して、対応するパーツを組み替え
- レシーバー、スコープ、マウントなどの子パーツを階層的に選択
- 選択中のパーツ構成、価格、重量、反動、エルゴノミクスを確認
- 弾薬を選択して、貫通力やダメージなどの性能を確認
- 価格や性能のターゲットラインを設定して、ビルドの目安を調整
- 作成したプリセットをJSONファイルとして保存・読込
- スマートフォンでも使いやすいレイアウトで操作

## 使い方

1. 武器カテゴリから使いたい武器を選びます。
2. パーツタブから交換したいスロットを選びます。
3. パーツカードを選ぶと、選択中の構成と性能が更新されます。
4. 弾薬パネルで使用する弾を選ぶと、弾薬性能を確認できます。
5. 必要に応じてプリセット名を入力し、JSONとして保存できます。

標準装備のパーツは、武器購入時についているものとして扱います。価格計算では、標準装備パーツのフリマ価格は加算しません。

## プリセット

作成したビルドはJSONファイルとして保存できます。

- `JSON保存`: 現在のビルドをPCに保存
- `JSON読込`: 保存済みのJSONからビルドを復元

プリセットJSONにはバージョン情報が含まれます。今後データ形式が変わった場合も、読み込み時に互換性を確認できるようにしています。

## データについて

武器、パーツ、弾薬データは tarkov.dev API をもとにしています。

公開版では、ビルド時に取得したデータをアプリに含めて配信します。そのため、利用者がAPIキーやサーバーを用意する必要はありません。
